Why zero-permission file access matters right now

Every day, millions of Android users download file managers that demand access to their contacts, location, and call history — just to view a PDF or a photo. A recent Hacker News post for "Gander", a zero-permission file viewer, gathered over 200 points and 72 comments in hours, showing a deep frustration with the status quo. Users are tired of apps that overreach, and they're actively seeking alternatives that respect their privacy.

Existing solutions like Google Files or Solid Explorer bundle file browsing with aggressive permission requests, cloud sync, and analytics. They are powerful, but they are not private. The demand for a lightweight, permission-free tool is not a niche developer fantasy — it's a consumer need that has been validated by the same privacy anxiety driving VPN adoption and browser fingerprint blocking.

Now is the perfect moment. With Android's Storage Access Framework (SAF), we can build a file viewer that requires zero permissions — no storage, no phone, no location. This isn't a hack; it's the platform's intended privacy-preserving API. And with the recent surge in privacy-focused tools on HN and Reddit, the audience is already looking for exactly what we're building.

How It Works

1

Open via SAF

ZeroFile uses Android's Storage Access Framework to let you pick any file from your device or cloud provider — without ever requesting storage permission. Your files stay under your control.

2

Filter & preview

Instantly filter your recent files by type: images, documents, audio, or video. See file size and modification date at a glance. No indexing, no background scanning — just fast, on-demand access.

3

Share or open

Use the system share sheet to send files to any app, or open them directly. ZeroFile is a viewer and launcher — it never stores, uploads, or tracks your activity. The APK is offline-first.

What You Get

0 Permissions

Unlike Google Files which demands storage, phone, and location, ZeroFile requests nothing. No contacts, no call history, no sensors. The app simply cannot access your private data — because it never asks.

Private by Design

No account, no analytics SDK, no network requests. ZeroFile works fully offline. We don't track you, we don't profile you, and we don't sell data. Your files stay on your device, period.

Fast & Light

The entire APK is under 2MB. No background processes, no notifications, no bloat. It launches instantly and sips battery. A file viewer should be quick and unobtrusive — not a resource hog.
