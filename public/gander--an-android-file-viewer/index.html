Why a zero-permission file viewer matters right now

Every day, millions of Android users install file managers that demand access to storage, location, phone, and contacts — just to browse a few folders. The recent HN thread (188 points, 65 comments) shows how much frustration exists around permission bloat. People are tired of apps that need "Storage" permission just to show a list of files.

Existing solutions like Solid Explorer or FX File Explorer require multiple permissions and often come with a price tag. Even open-source options like Amaze still request storage access by default. The only way to avoid this is to use the Storage Access Framework (SAF) — a system-level API that lets users pick a folder without granting app-wide access. But almost no file manager uses it as the default, because it's easier to just ask for permissions.

That's why Gander is different. It's built entirely on SAF, meaning it asks for zero permissions at install time. No storage, no location, no phone. Just a clean, fast, read-only file viewer. With Android 16 pushing for more restrictive storage access, the timing is perfect for a privacy-first alternative. The signal is clear: people want control, and they're willing to switch to a tool that respects that.

How It Works

1

Pick a folder

When you open Gander, you tap "Choose folder" and the system folder picker appears. You select any directory — Downloads, Documents, or an SD card — and Gander gets access to just that folder, nothing else.

2

Browse files instantly

Gander lists all files and subfolders with type icons, sizes, and modification dates. The interface is fast and minimal — no animations, no clutter. Just the information you need, presented clearly.

3

Open with any app

Tap any file and Gander hands it off to the system's default viewer — PDF reader, image gallery, or text editor. Gander never reads the file content itself, so your data stays between you and the app you choose.
