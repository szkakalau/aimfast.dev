## 1. What is it（这是什么）

Visual Studio 是微软出品的集成开发环境（IDE），面向 Windows 平台上的应用开发，支持 C#、C++、Python、JavaScript 等多种语言。它集成了代码编辑、调试、测试、版本控制和部署工具，是 .NET 生态的核心开发工具。对于独立开发者而言，它相当于一个"全家桶"式的开发工作台——从写代码到打包发布都能在一个窗口内完成。

## 9. Product Ideas（产品创意）

**产品一：VSAI Copilot 增强层**——为 Visual Studio 提供更精准的代码生成和重构建议，专注于 .NET 生态。现在做是因为微软原生 Copilot 偏通用，垂直场景仍有空白。

**产品二：VSMigrate**——一键将 VS Code 项目迁移到 Visual Studio 的工具，自动转换配置、映射快捷键、调整依赖。现在做是因为跨 IDE 迁移需求随 AI 工具普及而增长。

**产品三：VSPerf**——Visual Studio 性能分析仪表盘，可视化编译时间、内存占用和启动速度的优化建议。现在做是因为大型 .NET 项目的性能痛点长期未解决。
