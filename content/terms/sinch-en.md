## 1. What is it（这是什么）

Sinch 是一家提供云通信 API 的上市公司，核心业务是让开发者通过简单的 SDK 和 API 集成短信、语音、视频和即时消息（如 WhatsApp、Viber）能力。简单说，它是"通信基础设施即服务"——你的应用需要发验证码、做语音呼叫或推送通知时，Sinch 帮你搞定底层运营商对接和全球覆盖。对独立开发者而言，它类似 Twilio 的直接竞争对手，但更侧重欧洲市场和消息渠道聚合。
