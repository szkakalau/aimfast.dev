## 1. What is it（这是什么）
Neo.mjs 是一个基于 Web Worker 架构的现代 JavaScript 应用框架。它利用浏览器的多线程能力，将 UI 渲染、业务逻辑和数据处理分离到不同线程，从而避免主线程阻塞，实现流畅的用户界面。对于独立开发者来说，它就像是一个“不会卡顿”的 React 或 Vue，特别适合构建复杂、数据密集型的单页应用。

## 2. Why now（为什么现在）
现在出现是因为 Web 应用正变得越来越复杂——实时协作、大数据可视化、AI 交互等场景对性能要求极高。传统前端框架（如 React、Vue）受限于单线程，当应用变重时容易卡顿。Neo.mjs 通过 Web Worker 将计算任务移出主线程，直接解决了这个痛点。同时，浏览器对 Web Worker 的支持已非常成熟，开发者也更愿意接受多线程架构，技术条件和用户需求都已到位。
