## 1. What is it（这是什么）

WebGL 是一项允许浏览器无需插件即可渲染高性能 2D 和 3D 图形的 JavaScript API 标准。它基于 OpenGL ES 规范，利用 GPU 加速，让开发者能在网页中构建交互式 3D 场景、数据可视化和游戏。对独立开发者而言，WebGL 意味着你只需要一个浏览器和代码编辑器，就能做出过去需要安装客户端软件才能实现的图形应用。

## 2. Why now（为什么现在）

WebGL 本身并非新技术，但当前时间点的热度回升与几个因素叠加有关：浏览器对 WebGL 2.0 的全面支持已成熟，WebGPU 正在逐步落地但尚未完全取代；AI 生成 3D 内容（如 NeRF、高斯泼溅）需要浏览器端实时渲染，WebGL 是当前唯一普适的载体；同时，独立开发者对零安装、即开即用的产品形态需求持续上升。此外，近期在 GitHub Trending 上出现相关项目，说明开发者社区正在重新关注这一领域。
