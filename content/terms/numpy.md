## 1. What is it（这是什么）
NumPy 是 Python 生态中最核心的数值计算库，专门用于处理大规模多维数组和矩阵运算。它提供了高性能的数学函数，让开发者能用接近 C 语言的速度执行数组操作。对独立开发者而言，NumPy 是数据科学、机器学习、图像处理等领域的底层基石——几乎所有 Python 数据工具（如 Pandas、Scikit-learn）都依赖它。
