## 1. What is it（这是什么）

OceanBase 是一个分布式关系型数据库管理系统，由蚂蚁集团自主研发，主打金融级高可用、强一致性和水平扩展能力。它支持 MySQL 和 Oracle 兼容模式，能在普通服务器上实现高性能事务处理。对独立开发者而言，可以理解为一个"国产开源 PostgreSQL 替代品"——如果你在构建需要高并发写入、多活容灾的数据密集型应用，OceanBase 提供了一条不依赖 Oracle 或商业版 MySQL 的路径。

## 2. Why now（为什么现在）

OceanBase 出现在这个时间点，背后有三重推力：一是国产化替代浪潮——金融、政务等关键行业被要求替换国外数据库，OceanBase 是少数经过双十一峰值验证的国产方案；二是云原生趋势——OceanBase 4.x 版本大幅降低了资源门槛，支持单机分布式一体化，小团队也能低成本起步；三是开源策略转向——2021 年开源后社区热度持续积累，近期 GitHub Trending 出现说明开发者开始主动探索。市场对"分布式但易用"的数据库需求正在爆发。
