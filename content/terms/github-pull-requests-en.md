## 1. What is it（这是什么）

GitHub Pull Requests（拉取请求）是 GitHub 平台上的一种代码协作机制，允许开发者将分支中的代码变更提交给主分支，请求项目维护者审查并合并。它是现代开源协作的基石——开发者 fork 仓库、创建分支、提交改动，然后通过 Pull Request 发起合并请求，维护者可以在其中进行逐行评论、讨论修改建议，最终决定合并或关闭。对独立开发者而言，Pull Request 是参与开源、获取反馈、建立影响力的最直接入口。

## 2. Why now（为什么现在）

这个时间点出现 Pull Request 的独立趋势信号，并非因为该功能本身是新的——它早已是 GitHub 的核心功能——而是因为 AI 编程助手（如 Copilot、Cursor）正在改变代码审查和合并的节奏。开发者开始用 AI 批量生成代码变更，Pull Request 的数量和审查效率成为新的瓶颈。同时，2026 年远程协作和开源商业化加速，Pull Request 作为协作单元的价值被重新审视。Lobsters 技术社区在 2026-08-04 的提及，暗示开发者正在寻找更高效的 PR 工作流工具。
