## 1. What is it（这是什么）

Agent Skill 指的是赋予 AI Agent（智能体）在特定任务上可复用、可组合的“技能模块”。类似给 AI 装上“插件化能力”，比如“调用支付接口”“解析合同 PDF”“操作 Excel 表格”。对独立开发者而言，它相当于一套标准化的 AI 能力封装协议，让 Agent 不再只会聊天，而是能真正干活。

## 2. Why now（为什么现在）

2026 年，大模型从“对话”转向“执行”是核心主线。随着 GPT-5 级别模型普及，企业不再满足于问答，而是要求 Agent 直接完成业务闭环。同时，MCP（模型上下文协议）等标准化接口的成熟，让技能封装成为可能。此刻出现 Agent Skill 概念，恰逢 Agent 从“演示”走向“生产环境”的拐点，开发者需要一套通用语言来定义和交易这些能力。
