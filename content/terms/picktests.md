## 9. Product Ideas（产品创意）

1. **TestPick CLI**：一条命令分析当前 Git 分支的代码变更，自动运行最相关的 5 个测试。为什么现在做：GitHub Actions 的每次提交全量跑测试成本太高，开发者急需精准测试工具。
2. **PickTest Dashboard**：可视化展示测试用例的历史失败率、运行时间和代码关联度，帮助团队砍掉“僵尸测试”。为什么现在做：测试债务已成技术债主因，但市面上没有专门的清理工具。
3. **PickTest Bot**：接入 GitHub PR 评论，自动判断“这个 PR 需要跑哪些测试”，并给出“跳过哪些测试”的建议。为什么现在做：AI 代码审查已普及，但测试策略自动化仍是空白。
