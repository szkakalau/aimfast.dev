## 1. What is it（这是什么）

CSS（Cascading Style Sheets）是用于描述网页视觉呈现的标准样式表语言。它定义了 HTML 元素的布局、颜色、字体、动画和响应式行为，是 Web 三大核心技术之一。对独立开发者而言，CSS 是构建用户界面的基础工具——没有它，网页就是纯文本。当前 CSS 已演进到模块化版本，支持容器查询、嵌套、子网格等现代特性，但核心概念仍是"选择器 + 属性 + 级联规则"。
