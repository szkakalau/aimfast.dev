## 1. What is it（这是什么）

MariaDB 是一个开源的关系型数据库管理系统，由 MySQL 的原始开发者创建，作为 MySQL 的替代品而诞生。它完全兼容 MySQL 的协议和数据格式，意味着现有的 MySQL 应用可以无缝迁移。对独立开发者来说，MariaDB 就是那个"更开放、更快速、没有商业锁定的 MySQL"——如果你在找数据库，它几乎总是比 MySQL 本身更值得考虑的选择。

## 2. Why now（为什么现在）

MariaDB 出现在当前时间点并非偶然。随着 Oracle 对 MySQL 的商业化策略日益收紧，社区对开源数据库的信任正在持续流向 MariaDB。同时，AI 应用和边缘计算带来的数据密集型负载激增，开发者需要更灵活的数据库方案。MariaDB 在 JSON 支持和分布式存储方面的持续迭代，使其成为独立开发者在构建 AI 应用、实时分析工具时的默认选择。GitHub Trending 的出现也反映了开发者社区对它的关注正在升温。

## 4. Who's Behind It（谁在推动）

MariaDB 由 MariaDB Foundation 和 MariaDB Corporation 共同推动。基金会负责代码的开放治理，确保项目的社区属性；公司则提供企业级产品和服务。核心人物包括 MySQL 的创始人 Michael "Monty" Widenius，他的个人信誉是项目最大的信任资产。此外，全球范围内的数据库开发者社区、云服务商（如 AWS、Azure 提供 MariaDB 托管服务）也在持续推动其生态发展。
