## 1. What is it（这是什么）

GitHub Pages 是 GitHub 提供的免费静态网站托管服务，允许用户直接从 GitHub 仓库发布 HTML、CSS 和 JavaScript 站点。你只需要把代码推送到仓库，GitHub 就会自动构建并部署到 `username.github.io` 域名下。对于独立开发者来说，它是最低成本上线个人主页、项目文档或产品落地页的方式——零服务器费用、零运维负担，支持自定义域名和 HTTPS。

## 2. Why now（为什么现在）

这个时间点 GitHub Pages 重新引发关注，背后有几个驱动力：第一，AI 生成静态页面的效率大幅提升，开发者可以在几分钟内产出完整站点，托管需求随之增加；第二，云服务商持续涨价，开发者对"免费且可靠"的托管方案需求回升；第三，Jamstack 架构理念再度流行，静态站点配合 CDN 的体验已接近动态站点。Hacker News 上的讨论往往标志着开发者社区开始重新评估基础设施选型，这类话题通常在 1-2 周内扩散到更多技术社区。
