## 1. What is it（这是什么）

httpd 是 HTTP Daemon 的缩写，本质上就是一个 HTTP 服务器守护进程。你访问任何网站时，背后都有一个 httpd 在监听请求、返回页面。最著名的实现是 Apache HTTP Server，它的进程名就叫 httpd。对独立开发者来说，httpd 就是"跑在服务器上、专门处理网页请求的那个程序"——它是互联网基础设施中最基础也最不显眼的一环。
