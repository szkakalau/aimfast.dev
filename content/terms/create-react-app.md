## 1. What is it（这是什么）

Create React App（简称 CRA）是 Facebook 官方推出的 React 项目脚手架工具，用于零配置快速搭建单页应用。它内置了 Webpack、Babel、ESLint 等构建工具链，让开发者只需一条命令 `npx create-react-app my-app` 即可启动开发。对独立开发者而言，它是过去几年 React 入门和中小型项目启动的“默认选项”，但当前正面临社区维护停滞和替代方案崛起的转型期。

## 2. Why now（为什么现在）

CRA 在 2026 年 8 月 5 日于 Stack Overflow 被重新提及，且趋势评分高达 244.0/100，表明其正处于“旧技术被重新讨论”的临界点。核心驱动力有三：一是 React 官方已宣布 CRA 进入维护模式，社区急需替代方案；二是 Vite、Next.js 等工具链已成熟，开发者开始重新评估 CRA 的优劣势；三是 Stack Overflow 上的讨论往往代表“遗留项目维护者”的痛点集中爆发，这正是工具迁移和咨询服务的机会窗口。

## 4. Who's Behind It（谁在推动）

CRA 的原始推动者是 Facebook（现 Meta）的 React 团队，核心维护者包括 Dan Abramov 等知名工程师。但目前真正的“推动者”已转变为两类人：一是仍维护着大量 CRA 遗留项目的独立开发者和中小企业技术负责人，他们在 Stack Overflow 上寻求迁移方案；二是 Vite、Next.js、Remix 等替代工具的社区，他们通过对比文章和迁移指南，间接推动了对 CRA 的重新审视。当前没有新的商业公司直接推动 CRA 本身。

## 9. Product Ideas（产品创意）

1. **CRA-to-Vite CLI 工具**：一条命令自动分析项目依赖、重写配置、生成迁移报告。名称“cra2vite”。现在做是因为 Vite 生态已成熟，但迁移痛点仍未被标准化工具解决。
