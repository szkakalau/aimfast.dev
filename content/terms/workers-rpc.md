## 1. What is it（这是什么）

Workers RPC 是 Cloudflare 推出的远程过程调用（RPC）能力，让开发者能像调用本地函数一样，直接调用部署在 Cloudflare Workers 边缘网络上的其他 Worker 服务。通俗讲，它把“跨服务通信”从复杂的 HTTP 请求封装成了简单的函数调用，省去写 API 路由、鉴权、序列化的繁琐步骤。对独立开发者而言，这意味着构建微服务或跨项目复用代码时，代码会变得异常简洁。

## 2. Why now（为什么现在）

Workers RPC 出现的时机，恰逢边缘计算从“静态资源托管”转向“全栈应用平台”的关键拐点。Cloudflare 在 2026 年 8 月 4 日首次披露该能力，其核心逻辑是：当越来越多的应用逻辑运行在边缘节点时，服务间通信的延迟和复杂度成为瓶颈。传统 HTTP 调用在边缘场景下显得笨重，而 RPC 模式能显著降低延迟（函数调用比 HTTP 请求快一个数量级）。此外，这也顺应了“单体应用拆分为函数即服务（FaaS）”的行业趋势，开发者需要更底层的原生通信协议。
