## 1. What is it（这是什么）

ASP.NET Core 是微软推出的开源、跨平台 Web 框架，用于构建现代云应用、Web API 和微服务。它是经典 ASP.NET 的完全重写版本，不再绑定 Windows，可在 Linux、macOS 和容器中运行。对独立开发者而言，它意味着用 C# 一套代码，既能写后端服务，也能构建高性能 Web 应用，且完全免费。

## 2. Why now（为什么现在）

ASP.NET Core 本身已存在多年，但近期在 Stack Overflow 上重新被密集提及，背后是 .NET 生态在云原生和 AI 应用开发上的持续升温。微软持续投入性能优化，.NET 8/9 的 AOT 编译和原生云支持让它在容器场景中更具竞争力。同时，越来越多的独立开发者从 Node.js 和 Python 转向 C#，寻求强类型语言带来的安全性和生产力，这种迁移需求正在推动新的关注浪潮。
