## 1. What is it（这是什么）

LLM API 是大型语言模型能力的标准化接口封装。开发者通过 HTTP 请求调用 OpenAI、Anthropic、Google 等厂商的模型服务，无需自建 GPU 集群或训练模型，即可在应用内集成文本生成、代码补全、语义检索等 AI 能力。本质上是"按需购买智能"的云服务形态，类似 AWS 之于服务器，只是这里的"资源"是模型推理能力。

## 2. Why now（为什么现在）

2026 年，模型推理成本已降至 2023 年的约 1/20，API 调用成为中小团队接入 AI 的最低门槛路径。同时，多模态模型从实验走向生产，工具调用（function calling）和结构化输出成为 API 标配。更重要的是，大量传统 SaaS 正在经历"AI 重构"，而独立开发者是最早一批将 LLM API 嵌入工作流的群体——GitHub 上相关项目井喷正是这一迁移的早期信号。
