## 1. What is it（这是什么）
neomjs/neo 是一个开源的前端框架，旨在将 Web 应用的开发体验提升到桌面级应用的水平。它利用现代浏览器特性，实现了多线程架构和声明式 UI，让开发者能构建高性能、可扩展的复杂界面。对于独立开发者来说，它是一个比 React 或 Vue 更重但功能更强大的选择，特别适合需要处理大量数据和复杂交互的 Web 应用。

## 2. Why now（为什么现在）
当前 Web 应用正面临性能瓶颈，用户对响应速度和交互流畅度的要求越来越高。传统单线程框架在处理大数据量或复杂动画时力不从心。neomjs/neo 的多线程架构和桌面级设计理念，正好回应了这一需求。同时，浏览器对 Web Workers 和 SharedArrayBuffer 等底层 API 的支持日趋成熟，为这种框架提供了技术基础。独立开发者和 SaaS 创始人开始寻求能提升产品竞争力的工具，neo 的出现恰逢其时。
