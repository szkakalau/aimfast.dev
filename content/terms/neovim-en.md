## 1. What is it（这是什么）

Neovim 是一个基于 Vim 的现代开源文本编辑器分支，旨在通过重构架构、内置终端模拟器、异步插件系统和嵌入式 Lua 支持，解决 Vim 在扩展性和可维护性上的瓶颈。它保留了 Vim 的核心编辑体验，但用更现代的代码库和 API 让开发者能构建更强大的工具链。简单说，它是给 Vim 换了一颗更年轻的心脏，同时让插件生态有了更大的想象空间。

## 2. Why now（为什么现在）

这个时间点出现 Neovim 的讨论，核心驱动力是开发者工具链的"配置化"浪潮。随着 AI 编程助手（如 Copilot、Codeium）和 LSP（语言服务器协议）成为标配，开发者需要一个可深度定制、能无缝集成这些新工具的编辑器。Vim 的旧架构难以承载这些需求，而 Neovim 的异步模型和 Lua 嵌入恰好补上了这个缺口。此外，Zed、Cursor 等新编辑器的崛起，让 Vim 社区意识到需要一次"现代化反击"来留住用户。
