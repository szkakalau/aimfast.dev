## 1. What is it（这是什么）

Have I Been Pwned（HIBP）是一个数据泄露查询工具，用户输入邮箱或用户名，即可检查该账号是否出现在已知的数据泄露事件中。它由安全专家 Troy Hunt 于 2013 年创建，目前收录了超过 120 亿条泄露记录。对独立开发者而言，它本质上是一个"数据泄露搜索引擎"——通过 API 或网页端，快速判断用户凭据是否已被公开暴露。

## 2. Why now（为什么现在）

当前时间点（2026 年 8 月）出现这一趋势信号，背后有几个驱动力：第一，全球数据泄露事件频发，AI 驱动的钓鱼攻击让账号盗用成本骤降，用户对"我的密码是否已泄露"的焦虑达到历史高点；第二，主流浏览器和密码管理器开始原生集成泄露检测功能，市场教育已完成；第三，各国隐私法规（如 GDPR、CCPA 更新）强制要求企业提供泄露通知，B2B 合规需求激增。这个时间窗口恰好是"用户有意识、市场有需求、技术有接口"的三重叠加期。

## 9. Product Ideas（产品创意）

**① PwnWatch**——"实时泄露监控面板"：输入邮箱后持续监控多个泄露源，泄露发生时立即通过 Telegram/邮件通知，并附上"该密码是否仍在其他网站使用"的关联分析。现在做是因为用户对"被动查询"已疲劳，主动监控是自然升级。**② BreachScore**——"企业安全评分卡"：输入公司域名，自动扫描所有关联邮箱的泄露情况，生成可分享的评分报告。面向 HR 和 IT 管理员，现在做是因为企业合规需求正在爆发。**③ PwnGPT**——"泄露数据智能问答"：用 LLM 解析泄露数据，用户用自然语言提问"我的密码出现在几次泄露中？涉及哪些网站？"，现在做是因为 LLM API 成本已降到可接受范围。

值得关注的生态公司：Firefox Monitor（Mozilla 出品，基于 HIBP 数据）、Google Password Checkup（Chrome 内置功能）、Dashlane 和 1Password（密码管理器内置泄露检测）、DeHashed（商业泄露数据搜索）。这些公司验证了市场需求，但各有局限——Firefox Monitor 仅限 Firefox 用户，Google 仅限 Chrome 生态，密码管理器仅覆盖自家用户，独立开发者仍有差异化空间。
