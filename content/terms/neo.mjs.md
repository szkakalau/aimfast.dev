## 1. What is it（这是什么）
Neo.mjs 是一个基于 Web Worker 架构的 JavaScript 应用框架。它把 UI 渲染、业务逻辑和数据处理分别放在不同的 Worker 线程中运行，解决了传统前端框架（如 React、Vue）在主线程上执行所有操作导致的卡顿问题。简单说，它是一个“多线程前端框架”，目标是让复杂的 Web 应用像原生桌面软件一样流畅。

## 2. Why now（为什么现在）
当前 Web 应用越来越复杂，单线程的 JavaScript 已经无法满足高性能需求（如实时协作工具、数据可视化看板）。同时，Web Worker 的浏览器支持已超过 98%，且 Chrome 正在推广“多线程 Web”概念。Neo.mjs 恰好填补了“让开发者轻松使用多线程”的空白，无需手动管理 Worker 的通信细节。这个时间点出现，是因为底层技术成熟了，但开发者工具链还没跟上。
