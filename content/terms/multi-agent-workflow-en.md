## 1. What is it（这是什么）

Multi-Agent Workflow 是一种软件架构模式，让多个 AI Agent（智能体）在同一个流程中协作，各自负责不同的子任务，最终共同完成一个复杂目标。你可以把它想象成一支 AI 团队——一个负责拆解需求，一个负责写代码，一个负责测试，一个负责审查，彼此通过消息或共享状态进行协调。对独立开发者而言，这意味着你不再需要写一个巨大的单体 AI 应用，而是可以像搭积木一样组合多个专用 Agent。

## 2. Why now（为什么现在）

这个时间点出现 Multi-Agent Workflow 的升温，核心原因有三：第一，大模型 API 成本持续下降，让同时调用多个 Agent 变得经济上可承受；第二，主流框架（如 LangGraph、AutoGen、CrewAI）在过去半年里大幅降低了多 Agent 编排的技术门槛，从"论文级难度"降到了"周末项目级"；第三，开发者逐渐意识到单 Agent 在处理长链路任务时存在上下文丢失、错误累积等问题，多 Agent 分工协作天然规避了这些瓶颈。趋势评分 275.5 的高分也印证了市场关注度正在快速聚集。
