## 1. What is it（这是什么）

JDK 28 是 Java 开发工具包（Java Development Kit）的下一个版本代号，预计于 2026 年 9 月正式发布。它延续了 Java 半年一版的节奏，是 JDK 27 的后续版本。对于独立开发者而言，JDK 28 意味着更简洁的语法、更强的性能优化，以及可能引入的 Project Loom 和 Panama 相关特性进一步成熟。简单说：这是 Java 生态的"最新版工具箱"，值得关注但不必恐慌迁移。
