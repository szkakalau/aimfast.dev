## 1. What is it（这是什么）

react-vite 是一个将 React 框架与 Vite 构建工具结合的开发技术组合。Vite 是新一代前端构建工具，利用原生 ES 模块实现秒级冷启动和热更新，而 react-vite 指代使用 Vite 作为 React 项目脚手架和打包器的实践。它替代了传统的 Create React App（CRA），让开发者无需配置 Webpack 即可启动 React 项目，开发体验显著提升。

## 2. Why now（为什么现在）

React 官方在 2025 年已逐步将 CRA 标记为维护模式，并推荐 Vite 作为替代方案。与此同时，Vite 生态在 2026 年已趋成熟，插件市场丰富，社区教程数量激增。独立开发者对"零配置 + 极速热更新"的需求在 AI 辅助编码时代被放大——每次代码修改的反馈速度直接影响开发效率。Stack Overflow 在 2026-08-04 首次出现该术语的独立讨论，标志着这一组合正在从"隐性实践"走向"显性命名"。
