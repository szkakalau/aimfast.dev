## 1. What is it（这是什么）

Visual Studio 是微软出品的集成开发环境（IDE），简单说就是程序员写代码、调试、打包发布的一站式工作台。它支持 C#、C++、Python、JavaScript 等几十种语言，内置编译器、代码补全、图形化调试器和数据库工具。对独立开发者而言，它是 Windows 平台开发桌面应用、游戏（Unity 脚本）和 Azure 云服务的默认入口，相当于“Windows 开发者的瑞士军刀”。
