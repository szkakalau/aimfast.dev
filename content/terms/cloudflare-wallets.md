## 1. What is it（这是什么）

Cloudflare Wallets 是 Cloudflare 推出的原生加密钱包基础设施服务，允许开发者在无需自建复杂区块链后端的情况下，在应用内快速集成钱包创建、密钥管理和交易签名功能。它本质上是把钱包后端做成 API 服务，开发者通过几行代码即可调用。你可以把它理解为“钱包界的 Stripe”——不需要自己处理私钥存储、链上交互等底层逻辑，专注做自己的业务功能即可。
