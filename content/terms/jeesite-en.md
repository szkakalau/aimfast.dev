## 1. What is it（这是什么）

JeeSite 是一个基于 Java 的企业级快速开发平台，集成了用户权限管理、内容管理、定时任务、工作流等核心模块。它提供了一整套前后端分离的代码生成器，开发者可以通过配置实体类快速生成 CRUD 代码和页面。简单说，它是一个"脚手架"，让 Java 开发者跳过繁琐的基础搭建，直接进入业务逻辑开发。对于独立开发者而言，JeeSite 意味着可以在一周内交付原本需要一个月的中小型企业管理系统。

## 2. Why now（为什么现在）

当前企业数字化转型进入深水区，大量中小型企业需要内部管理系统（OA、CRM、ERP），但预算有限，无法承担定制开发的高昂成本。与此同时，Java 技术栈在企业市场仍占主导地位，而低代码平台的兴起教育了市场——企业主开始接受"快速生成"的交付模式。JeeSite 恰好填补了"传统 Java 开发"与"低代码平台"之间的空白，它保留了代码的完全可控性，同时大幅压缩了开发周期。2026 年 AI 辅助编程工具的普及也让这类脚手架平台的价值被重新评估——开发者希望有一个稳定、规范的基础框架来承载 AI 生成的业务代码。
