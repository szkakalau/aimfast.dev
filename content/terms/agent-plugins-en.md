## 1. What is it（这是什么）

Agent Plugins 是 AI Agent 生态中的一种插件机制，允许开发者将特定能力、工具或数据源以标准化接口挂载到 AI 代理上，让 Agent 在对话或任务执行中动态调用这些插件，完成搜索、支付、数据库操作等具体动作。简单说，它就像给 AI Agent 装上"外接设备"，让 AI 不只是聊天，而是能真正动手做事。对独立开发者而言，这是一个低门槛切入 AI 应用层的入口。

## 2. Why now（为什么现在）

当前 AI Agent 正从"能说"走向"能做事"，但通用 Agent 无法覆盖所有垂直场景——这正是插件生态爆发的窗口。Vercel 等基础设施玩家开始布局 Agent 相关工具链，表明市场正从模型层竞争转向应用层生态竞争。同时，MCP（Model Context Protocol）等标准化协议的成熟，降低了插件开发的技术门槛，让独立开发者可以用少量代码接入主流 Agent 框架。用户侧，企业对"AI 能直接完成工作"的需求已经从尝鲜变为刚需，催生了插件市场的早期红利。
