## 1. What is it（这是什么）
GitHub Actions 是 GitHub 内置的自动化工作流引擎。你可以把它理解为“代码仓库里的机器人管家”：当你在 GitHub 上推送代码、提 Issue 或发 Pull Request 时，它能自动帮你执行测试、构建、部署等重复性任务。对独立开发者而言，它相当于免费的 CI/CD（持续集成/持续部署）服务，让你不用自己搭服务器就能实现“代码提交后自动上线”。

## 2. Why now（为什么现在）
