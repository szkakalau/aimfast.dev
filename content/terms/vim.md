## 1. What is it（这是什么）
Vim 是一个高度可配置的文本编辑器，旨在高效创建和更改任何类型的文本。与普通编辑器不同，它使用**模式编辑**：你可以在“插入模式”下打字，在“普通模式”下用快捷键移动和操作代码，无需鼠标。对独立开发者而言，Vim 是一套“手指体操”，学会后能极大提升代码编写速度，但学习曲线陡峭。

## 2. Why now（为什么现在）
Vim 并非新技术，但近期在 Hacker News 被提及（2026-07-30），表明其社区仍在活跃讨论。当前市场趋势是**远程工作和开发者工具效率化**：开发者追求减少鼠标依赖、提升键盘操作效率的工具。同时，VS Code 等现代编辑器的 Vim 插件（如 VSCodeVim）让新用户能低风险尝试 Vim 操作模式，降低了入门门槛。
