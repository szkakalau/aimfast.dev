## 1. What is it（这是什么）

Vercel WAF 是 Vercel 平台推出的一款 Web 应用防火墙服务，旨在为部署在 Vercel 上的前端应用和 API 提供实时安全防护。它通过边缘网络拦截恶意流量，防止常见的网络攻击（如 SQL 注入、跨站脚本攻击），让独立开发者无需手动配置复杂的安全规则，就能为项目加上一道“安全门”。
