## 1. What is it（这是什么）

JeeSite 是一个基于 Java EE（企业级 Java）技术栈的快速开发平台，提供代码生成器、权限管理、工作流等基础模块，帮助开发者快速搭建企业级后台管理系统。你可以把它理解为“Java 世界的脚手架”——省去重复搭建框架的时间，直接聚焦业务逻辑。它类似于 Ruby 界的 Rails 或 Python 界的 Django，但更贴近国内企业级项目的技术习惯。
