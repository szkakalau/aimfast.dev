## 1. What is it（这是什么）

MariaDB 是一个开源的关系型数据库管理系统，由 MySQL 的创始团队在 MySQL 被甲骨文收购后，于 2009 年创建的分支。它保持与 MySQL 的高度兼容性，同时增加了更多存储引擎和性能优化。对独立开发者而言，它是一个免费、可替代 MySQL 的数据库，用于存储和管理应用数据，支持 SQL 查询、事务处理等核心功能。
