## 1. What is it（这是什么）

Ruby 是一种动态、开源的编程语言，由松本行弘于 1995 年发布，强调"程序员快乐"的设计哲学。它以简洁优雅的语法著称，配合 Rails 框架，让开发者能在极短时间内构建完整的 Web 应用。对独立开发者而言，Ruby 意味着"用最少的代码实现最多的功能"——非常适合快速验证产品想法，尤其适合构建 CRUD 类应用、内部工具和 API 服务。
