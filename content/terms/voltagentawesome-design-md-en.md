## 9. Product Ideas（产品创意）

**创意一：DesignDoc**——一个 Markdown 设计文档生成器，自动将设计规范、组件说明、设计决策记录整理为结构化文档。为什么现在做：设计团队正在从 Figma 向代码库迁移文档，这个工具填补了中间空白。

**创意二：MD2UI**——将 Markdown 描述直接渲染为可交互的 HTML 原型，支持导出为 React/Vue 组件。为什么现在做：AI 编程助手（如 Cursor、Copilot）让文本到代码的转化成为常态，但缺少专门针对 UI 的优化层。

**创意三：DesignTok**——一个基于 Markdown 的 Design Token 管理工具，支持版本控制、跨平台同步和自动生成 CSS 变量。为什么现在做：设计系统团队正在寻找比 Style Dictionary 更轻量的替代方案。
