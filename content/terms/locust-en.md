## 1. What is it（这是什么）

Locust 是一个开源负载测试工具，用 Python 编写，允许开发者用代码定义用户行为，然后模拟成千上万的并发用户访问你的系统。核心逻辑是：你写一段普通的 Python 脚本描述用户会做什么，Locust 负责把这段脚本跑出压力来。对独立开发者而言，它是在上线前验证你的服务能否扛住真实流量冲击的免费方案。

## 2. Why now（为什么现在）

当前正值 AI 应用和微服务架构爆发期，独立开发者部署的服务越来越多，但负载测试工具要么太贵（如 LoadRunner），要么太复杂（如 JMeter 的 XML 配置）。Locust 的 Python 原生体验契合了当下主流开发者栈，加上 Serverless 架构的普及让"压测"变成了部署前的刚需动作。它出现在这个时间点，是因为"用代码定义压测"这个理念终于等到了 Python 开发者成为主流人群的窗口期。
