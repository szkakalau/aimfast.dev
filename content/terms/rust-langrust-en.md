## 1. What is it（这是什么）

rust-lang/rust 是 Rust 编程语言的官方开源仓库，托管在 GitHub 上，由 Rust 基金会和核心团队维护。它是这门系统级语言的全部源码、编译器实现、标准库和文档的家。对独立开发者来说，Rust 以内存安全、零成本抽象和极高性能著称，常被用来构建 CLI 工具、WebAssembly 模块、网络服务甚至操作系统组件。简而言之，这是 Rust 语言本身的“源代码大本营”。

## 2. Why now（为什么现在）

Rust 连续多年在 Stack Overflow 开发者调查中被评为“最受喜爱的语言”，但真正推动其爆发的转折点是 2024 年 Linux 内核开始正式接受 Rust 代码，以及各大云厂商（AWS、微软）将其纳入核心基础设施。与此同时，AI 工具链（如 Hugging Face 的 candle）和 WebAssembly 生态的成熟，让 Rust 从“系统编程小众语言”变成了“独立开发者构建高性能工具的首选”。2026 年，Rust 在嵌入式、边缘计算和 AI 推理场景的渗透率正在加速，这个时间点恰好是生态从早期采用迈向主流的关键窗口。
