## 1. What is it（这是什么）

Laravel 是一个 PHP 全栈 Web 开发框架，为开发者提供路由、数据库 ORM（Eloquent）、模板引擎（Blade）、认证、队列等开箱即用的工具。它让开发者用更少的代码构建现代 Web 应用，语法优雅、生态丰富，是目前全球最流行的 PHP 框架之一。简单说，它是 PHP 世界的“瑞士军刀”，能大幅降低 Web 应用的开发时间和维护成本。
