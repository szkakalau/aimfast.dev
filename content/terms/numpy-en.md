## 1. What is it（这是什么）
NumPy 是 Python 生态中最核心的数值计算库，提供了高性能的多维数组对象和丰富的数学函数。简单说，它是 Python 做科学计算、数据分析和机器学习的“地基”——几乎所有数据相关工具（如 Pandas、TensorFlow）都依赖它。独立开发者可以用它快速处理矩阵运算、线性代数、随机数生成等任务，比纯 Python 快几十倍。
