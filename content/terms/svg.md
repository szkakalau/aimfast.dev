## 1. What is it（这是什么）

SVG（Scalable Vector Graphics，可缩放矢量图形）是一种基于 XML 的开放标准图像格式，用于在网页上描述二维矢量图形。与位图（如 PNG/JPG）不同，SVG 由数学路径和形状定义，因此任意缩放不失真，且文件体积小、可编程、可交互。对独立开发者而言，SVG 是构建图标、图表、动画、数据可视化和 UI 组件的“代码级”素材，可直接嵌入 HTML 并通过 CSS/JavaScript 控制。

## 2. Why now（为什么现在）

SVG 并非新技术，但当前时间点出现新热度，核心驱动力有三：第一，AI 生成代码（如 Claude、GPT-4o）能直接输出 SVG 代码，大幅降低了开发者手工编写矢量图形的门槛；第二，现代浏览器对 SVG 的渲染性能与 CSS 动画支持已完全成熟，HDR 和可变字体等新特性与 SVG 结合催生新交互形态；第三，设计工具（Figma）默认导出 SVG，使设计到代码的转化链路标准化。2026-08-01 的 Reddit 提及暗示社区正在重新评估其在新场景（如 AI 图标生成）中的价值。
