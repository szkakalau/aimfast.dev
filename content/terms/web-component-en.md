## 1. What is it（这是什么）

Web Component 是一组 W3C 标准 API 的统称，允许开发者封装自定义 HTML 标签，使其自带样式、结构和行为，实现真正的组件复用。它由 Custom Elements、Shadow DOM 和 HTML Templates 三块核心组成。对独立开发者来说，它意味着写一次组件，就能在任何现代浏览器和框架中使用，不依赖 React、Vue 或 Angular 的运行时。

## 2. Why now（为什么现在）

Web Component 并非新概念，但当前时间点出现了几个关键变化：一是浏览器支持度已接近 100%，Safari 和 Firefox 补齐了多年的兼容短板；二是 AI 生成代码的爆发让"可移植、无依赖"的组件标准变得更有价值——AI 生成的原生组件可以避免框架锁定的麻烦；三是前端框架开始互相借鉴，Lit、Stencil 等轻量库让 Web Component 的开发体验大幅提升。这些因素叠加，让它在开发者社区重新被关注。
