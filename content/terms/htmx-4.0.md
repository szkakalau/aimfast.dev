## 1. What is it（这是什么）
Htmx 4.0 是一个前端库，允许你直接在 HTML 中使用属性（如 `hx-get`、`hx-post`）发起 AJAX 请求、触发 CSS 过渡和 WebSocket 通信，而无需编写 JavaScript。它旨在用简单标记替代复杂的前端框架，让后端开发者能快速构建动态 Web 应用。对于独立开发者，这意味着更低的构建成本和更快的迭代速度。
