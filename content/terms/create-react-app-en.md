## 1. What is it（这是什么）

Create React App 是 Facebook（现 Meta）官方推出的 React 项目脚手架工具，用于零配置快速搭建单页应用。开发者只需一条命令 `npx create-react-app my-app`，即可获得完整的构建链——包括 Babel、Webpack、开发服务器和测试框架，无需手动配置任何工具链。它曾是 React 生态的默认起点，但如今因维护停滞、构建速度慢，正被 Vite 等现代工具快速替代。对独立开发者而言，它更像一个"历史遗留选项"，而非新项目的首选。

## 2. Why now（为什么现在）

这个时间点出现关注，核心原因是 React 官方文档已正式将 Create React App 标记为"不建议用于新项目"，并推荐 Vite、Next.js 等替代方案。与此同时，React 19 的发布进一步拉大了 CRA 与新版 React 特性之间的兼容性鸿沟——CRA 的 Webpack 配置难以支持 React Compiler 等新工具链。Stack Overflow 上的单次提及，大概率是开发者遇到迁移问题时产生的求助帖。市场情绪正从"默认使用"转向"主动淘汰"，这恰恰是分析其残余价值和迁移机会的最佳窗口。
