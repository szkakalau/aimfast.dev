## 1. What is it（这是什么）

Kotlin Agent Development Kit 是一个面向 Kotlin 开发者的智能体（Agent）开发工具包。它让你能用 Kotlin 语言快速构建、部署和管理 AI Agent，就像用 LangChain 做 Python 那样，但针对 JVM 生态做了深度优化。简单说，这是 Kotlin 版的 AI Agent 开发框架，适合那些想用 Java/Kotlin 技术栈做 AI 应用的人。

## 2. Why now（为什么现在）

## 9. Product Ideas（产品创意）

1. **KAgent Studio**：一个可视化 IDE 插件（基于 IntelliJ），让 Kotlin 开发者拖拽式构建 Agent 工作流。为什么现在做？因为 IntelliJ 是 Kotlin 开发者的标配，插件生态有巨大空白。
2. **Kotlin Agent Hub**：一个开源社区驱动的 Agent 组件市场，类似 npm 但针对 Kotlin Agent。为什么现在做？因为 Kotlin 缺少类似 LangChain Hub 的生态。
3. **AgentKt**：一个轻量级 Kotlin 库，封装 OpenAI/Anthropic API 并提供类型安全的 Agent 构建 DSL。为什么现在做？因为现有 Java 方案（如 LangChain4J）太重，Kotlin 开发者想要更简洁的体验。
