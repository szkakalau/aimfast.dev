## 1. What is it（这是什么）

JEP 401 是 OpenJDK 提出的一个 Java 增强提案（JDK Enhancement Proposal），核心目标是引入**原始类型（Primitive Types）**的泛型支持，即让 `int`、`long`、`double` 等基础类型可以直接作为泛型参数使用，例如 `List<int>`。这意味着 Java 开发者不再需要为了放进集合而把原始类型装箱为 `Integer`、`Long`，从而大幅减少内存开销和性能损耗。对独立开发者而言，简单理解就是：**Java 终于要原生支持"值类型集合"了**，写起来更简洁，跑起来更快。
