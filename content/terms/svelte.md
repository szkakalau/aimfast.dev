## 1. What is it（这是什么）

Svelte 是一个前端 UI 框架，与 React 或 Vue 不同，它**没有虚拟 DOM**。它通过编译阶段将组件代码转换为高效的纯 JavaScript，因此浏览器加载时无需携带框架运行时。对独立开发者而言，这意味着**更小的包体积**（通常比 React 应用小 30%-50%）和**更快的页面加载速度**。你可以把它理解为"预编译"的 React——写起来像组件，跑起来像原生 JS。
