## 1. What is it（这是什么）

gccrs 是 GNU 编译器套件（GCC）中正在开发的 Rust 编程语言前端。简单说，它让 GCC 能直接编译 Rust 代码，而不依赖 Rust 官方的 rustc 编译器。对独立开发者而言，这意味着未来可以用 GCC 生态的优化能力和交叉编译支持来构建 Rust 项目，同时减少对单一编译器的依赖。

## 2. Why now（为什么现在）

Rust 语言已连续多年被评为最受开发者喜爱的语言，但编译器 rustc 存在编译速度慢、内存占用高的问题。GCC 作为老牌编译器，拥有成熟的优化管道和广泛的硬件架构支持。2026 年这个时间点，Rust 官方与 GCC 基金会合作已进入实质阶段，gccrs 项目正从实验性走向可用性验证，目标是让 Rust 代码能在更多嵌入式平台和旧架构上编译运行。
