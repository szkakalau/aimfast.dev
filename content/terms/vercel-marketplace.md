## 1. What is it（这是什么）

Vercel Marketplace 是 Vercel 公司推出的一个应用市场/插件生态平台，让开发者可以在 Vercel 的部署环境中发现、安装和管理第三方服务与集成工具。你可以把它理解为“前端部署界的 App Store”——就像 Shopify App Store 之于电商，Vercel Marketplace 之于前端应用。它让开发者无需离开 Vercel 控制台，即可一键接入数据库、认证、支付、监控等服务，省去繁琐的 API 配置和密钥管理。

## 2. Why now（为什么现在）

Vercel 已从“部署工具”演变为“前端云平台”，2024-2026 年间其 Next.js 框架和 Edge Network 生态持续扩张，但服务集成仍依赖手动配置。随着 AI 应用和全栈框架（Next.js 14+ Server Actions）普及，开发者迫切需要“开箱即用”的集成体验。同时，Vercel 在 2025 年推出的 v0 和 AI SDK 已积累大量开发者，Marketplace 是自然延伸——将流量转化为平台收入，对标 AWS Marketplace 和 Netlify Integrations 的竞争压力。此刻推出正是生态成熟信号。
