## 1. What is it（这是什么）

IntelliJ IDEA 是 JetBrains 出品的 Java 集成开发环境（IDE），被广泛认为是 Java 和 Kotlin 开发的事实标准工具。它提供智能代码补全、深度重构、内置版本控制、调试器和大量插件生态。对独立开发者而言，它本质上是"写 Java/Kotlin 代码时最趁手的工具箱"——社区版免费，旗舰版收费，覆盖从 Web 后端到 Android 开发的完整场景。
