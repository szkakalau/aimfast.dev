## 这是什么  
Agent-Friendly AI Database 是一种专为 AI Agent 设计的数据库，旨在优化 Agent 对数据的自主读写、推理与交互能力。它强调支持自然语言查询、实时上下文感知以及动态数据整合，以匹配 Agent 的工作流需求。据信源预测，到 2028 年，三分之一的企业软件交互将由 Agent 完成，这要求数据库底层架构主动适应 Agent 而非传统应用。
