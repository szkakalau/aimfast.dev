## 这是什么  
Distributed Git for AI Agents 是一种面向人工智能代理的分布式版本控制系统，由前 GitHub CEO 提出。它旨在解决多个 AI 代理在协作编写代码时产生的信任与版本管理问题，类似于传统 Git 对开发者团队的作用。
