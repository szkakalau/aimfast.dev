## What is it

AI-Native Code Presentation is a new breed of developer tool that lets you create animated, interactive code walkthroughs without heavy dependencies. Think of it as a marriage between a slide deck and a live coding environment, but built from the ground up for the AI era. Instead of static code blocks in a Markdown file, you get components that can step through code line by line, highlight syntax dynamically, and even respond to user input in real time. The key insight is that these tools are "AI-native" because they assume an AI assistant might generate or modify the presentation content, and they're built as lightweight web components that work without frameworks like React or Vue. For an indie developer, this means you can embed beautiful, interactive code tutorials into your docs or product demos with minimal overhead.

## Why now

This trend is emerging now because of three converging forces. First, developer expectations have been raised by tools like GitHub Copilot and Cursor—developers now expect AI-enhanced experiences everywhere, including documentation and presentations. Second, the web component standard has finally matured across browsers, making it practical to build dependency-free UI elements that work anywhere. Third, the indie developer community has been vocal about wanting lighter alternatives to heavy tools like Reveal.js or Spectacle. The "showhn" source where this was first spotted is a strong signal: hackers are tired of bloated presentation tools and are building their own. The timing is right because AI code generation is mainstream, but the tools to present that code beautifully are still primitive.

The open-source nature means contributions come from developers who need these tools for their own projects—documentation writers, course creators, and tool builders.
